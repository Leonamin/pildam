# 알려진 위험과 미검증 항목

2026-10-18 프로토타입 QA(연습용 AI, 실제 브라우저 1280·375·360px, 다크 모드) 기준.

## 다시 확인할 것

- **서버 재시작 뒤 글 유실 (1회, 재현 안 됨)**: 서버가 꺼진 동안 쓴 글이 다시 시도 후 "저장됨"으로 표시됐는데, 새로고침하니 파일에 없었다. 같은 순서로 두 번 더 해 봤을 때는 정상이었다. 대비책으로 API 응답 캐시 금지와 "저장 안 된 글이 있으면 떠나기 전에 확인"을 넣었다.

## 남은 위험

- AI 쓰기를 멈추거나 화를 바꿔 중단하면 쓴 부분과 스냅샷은 남지만 지시 기록이 없어 AI 패널에 되돌리기 버튼이 없다. "이전 버전"에서만 되돌릴 수 있다.
- AI 패널의 되돌리기는 기록과 스냅샷을 시각(2분 이내)으로 짝지어서, 적용하지 않은 선택 수정 기록 옆에 근처 다른 스냅샷의 되돌리기가 보일 수 있다.
- 관계도 저장은 nodes·edges가 배열인지만 검사한다.
- 로그인 실패 제한은 `CF-Connecting-IP`를 믿는다. 터널 뒤에서 127.0.0.1에만 바인딩할 때만 안전하다.
- AI 한도 초과 판별은 실제 오류 문구를 보지 못한 추정이다. [ADR 0010](../decisions/0010-isolated-cli-execution.md)

## 미검증

- 실제 CLI로 선택 수정·요약·새 작품 초안의 JSON 해석 (연습용 AI로만 확인. 대필 스트리밍은 세 CLI 모두 확인)
- `deploy/deploy.sh` 실행과 systemd 서비스 설치
- 태블릿 폭, 터치 제스처(선택·끌기)
- Storybook 스토리 38개 중 20개는 빌드만 확인
