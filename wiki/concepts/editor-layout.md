# 작업 화면 구성

레퍼런스: [UI 레퍼런스](../references/ui-references.md)의 1·2번(종이 원고 중심 에디터).

## 데스크탑

```
┌───┬──────────┬───────────────────────────┬──────────────┐
│ 🏠 │ 1화 비 오는 │                           │  AI           │
│ 📖 │ 2화 재회    │      [ 종이 원고 ]          │  ─ 작성 기록 ─  │
│ 🕸 │ 3화 ...    │   세리프체 · 넓은 여백        │  "3문단 작성함" │
│   │ + 새 화     │                           │  [되돌리기]     │
│   │            │                           │  [아이디어 입력] │
└───┴──────────┴───────────────────────────┴──────────────┘
                ╭─────────────────────────╮
                │  📑 목차   📄 원고   ✨ AI  │  ← 떠 있는 전환 버튼
                ╰─────────────────────────╯
```

- 왼쪽 아이콘 줄: 홈 · 원고 · 관계도.
- 목차: 챕터 목록, 세계관 · 문체 · 메모. 항목을 누르면 가운데에 열린다.
- 가운데: 종이 느낌의 원고. 세리프체, 넓은 여백.
- 오른쪽: AI 패널. 작성 기록과 아이디어 입력창.

## 떠 있는 전환 버튼

- 화면 아래 가운데에 항상 떠 있다. 누를 때마다 목차 · 원고 · AI 패널이 켜지고 꺼진다.
- 페르소나를 고려해 아이콘과 글자를 함께 표시한다.
- 모두 끈 상태에서는 빈 화면 가운데에 "원고 열기 / AI 열기" 큰 버튼을 보여 준다.

## 모바일

- 한 번에 패널 하나만 보여 준다. 떠 있는 버튼이 탭 전환 역할을 한다.
- 선택 수정 메뉴는 화면 아래 시트로 띄운다.

## 구현 결과 (2026-10-18)

- 주소에 현재 위치를 남긴다: `/works/:id?ch=<화ID>`, 설정 문서는 `?doc=world|style|notes`. 새로고침해도 같은 곳이 열린다.
- 패널 켜짐 상태는 기기별로 localStorage에 저장한다. 꺼진 패널도 화면에서 숨길 뿐 유지돼서 실행 취소 기록과 AI 강조가 사라지지 않는다.
- 태블릿(768~1023px)에서는 목차가 겹쳐 열리는 서랍이다. 데스크탑 열 너비는 목차 240px, AI 320~360px.
- 원고는 18px, 줄 간격 1.9. 저장 상태(저장됨 / 저장 중… / 저장 실패 · 다시 시도)를 화 제목 옆에 보여 준다. 1.2초 뒤, 포커스를 잃을 때, 화를 바꿀 때, 페이지를 떠날 때 저장한다.
- 새 작품 시작 흐름: 질문 3개(이야기, 주인공, 느낌 — 느낌은 예시 칩) → AI 초안(제목·세계관·문체·인물 관계 제안) 검토 → 이대로 시작 → 1화. "건너뛰고 빈 작품으로 시작"도 있다.

## 설정 노트 트리와 공통 AI 패널 (2026-10-18 갱신)

- 목차의 설정 영역: 문체(단일 문서) + 폴더별 노트 트리 + 관계도 링크. 폴더 접힘 상태는 기기별로 기억한다. 주소는 `?note=<노트ID>`, `?doc=style`.
- 3,000자 이상이고 폴더에 혼자 있는 노트에는 "제목별로 나누기" 안내 버튼이 뜬다.
- 오른쪽 AI 패널은 화·문체·노트·관계도 모두에서 같은 셸(AI 고르기, 대상별 기록, 노트 붙이기, 오류 안내)을 쓰고, 대상에 따라 동작만 바뀐다.
