# MVP 기능 범위

| # | 기능 | 내용 |
|---|---|---|
| 1 | 로그인 | 아이디·비밀번호. 계정 2개는 서버 설정 파일에 둔다. 회원가입 없음. [ADR 0004](../decisions/0004-id-password-auth.md) |
| 2 | AI 선택 | 운영자가 허용한 모델 목록 안에서 언제든 변경. 표시는 `별명 (모델 원문)`, 별명이 없으면 원문만. 기본값 Gemini 4 Argon |
| 3 | 보안 | CLI는 빈 작업 폴더에서 도구 없이·읽기 전용 샌드박스로 실행 |
| 4 | 홈 | 작품 카드 목록(제목, 마지막 수정 시간), 새 작품 버튼 |
| 5 | 작업 화면 | 목차 · 원고 · AI 패널, 떠 있는 전환 버튼. [작업 화면 구성](editor-layout.md) |
| 6 | 작품 구조 | 세계관 · 문체 · 관계도(인물·장소·세력) · 챕터 · 메모 |
| 7 | 에디터 | 서식 없는 원고. 마크다운 문법 노출 없음. [ADR 0006](../decisions/0006-tiptap-with-plain-text-storage.md) |
| 8 | 선택 수정 | 문장 선택 → 다시 쓰기 / 이어 쓰기 / 묘사 더하기 / 직접 요청 → 후보 3개 → 적용 |
| 9 | 대필 | 아이디어 입력 → AI가 원고에 바로 작성 → 피드백으로 조정. [AI 작성 흐름](ai-writing-flow.md) |
| 10 | 컨텍스트 관리 | 대화를 쌓지 않고 매번 새로 조립. [컨텍스트 조립](context-assembly.md) |
| 11 | 되돌리기 | 자동 저장 + AI 적용 직전 스냅샷. 화면에는 "이전 버전으로 되돌리기" 목록만 |
| 12 | 챕터 요약 | 챕터를 넘어가면 AI가 요약을 만들어 다음 화 작성에 사용 |
| 13 | 관계도 | 등장인물·세계관을 그래프로, 회차별 관계 변화 표시. [관계도](relationship-graph.md) |
| 14 | 설정 제안 | 새 인물·관계 변화가 나오면 "설정에 반영할까요?" 카드 |

## 미룬 기능

- 작품 썸네일 생성 (GPU PC 연결 가능)
- 내보내기 (EPUB / Word)
- 맞춤법 검사
- 실시간 공동 편집
