# 제품 개요

**필담**은 친구 한 명과 운영자(나), 두 사람만 쓰는 비공개 AI 소설 작성 웹 서비스다. 도메인은 `pildam.leonamin.com`이다.

## 목적

- 아이디어를 던지면 AI가 대필하고, 피드백으로 계속 조정하며, 일부 문장은 직접 고치는 작성 방식을 지원한다.
- 서버 PC에 로그인된 AI CLI(Claude Code, Codex, Antigravity)를 사용해 **추가 지출 없이** 운영한다. AI 선택권은 운영자가 가진다.

## 사용자 페르소나

- 20대 한국인 여성. 컴퓨터로 일하거나 배우는 직군이 아니다.
- AI는 채팅만 써 봤다. Codex, Antigravity 같은 도구를 모르고 마크다운 문법도 쓰지 못한다.
- 이전에는 운영자가 Antigravity를 켜고 폴더·모델을 설정해 주면 파일 열고 닫기만 하며 썼다.

## 사용자 피드백 (Antigravity 사용 경험)

| 구분 | 내용 |
|---|---|
| 좋았던 점 | Gemini 4 Argon 모델의 글 |
| 좋았던 점 | 원하는 구문만 선택해 수정·추천받기 |
| 불편했던 점 | 채팅이 길어지면 AI가 점점 멍청해진다 (컨텍스트 누적) |
| 바라는 점 | AI에 익숙하지 않아도 편하게 쓸 수 있을 것 |
| 작성 스타일 | AI가 대필하고, 아이디어를 던지며 AI가 계속 조정, 일부 문장은 직접 수정 |
