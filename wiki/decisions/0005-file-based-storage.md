# 0005. 데이터는 파일로 저장한다

## 결정

데이터베이스 없이 작품별 폴더에 텍스트·JSON 파일로 저장한다. [데이터 구조](../concepts/data-layout.md)

## 근거

- 사용자가 두 명뿐이다.
- 폴더 복사로 백업된다.
- 원고가 일반 텍스트라 AI에 그대로 넘길 수 있고 사람이 직접 읽을 수 있다.

## 한계

- 동시 편집은 충돌 경고만 한다. 사용자가 늘거나 실시간 공동 편집이 필요해지면 다시 검토한다.
