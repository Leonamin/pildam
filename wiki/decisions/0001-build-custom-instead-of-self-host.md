# 0001. 기존 프로젝트 대신 직접 만든다

## 맥락

셀프호스팅할 수 있는 AI 소설 도구와 AI CLI 웹 래퍼를 조사했다. [기존 프로젝트 조사](../references/existing-projects.md)

## 결정

기존 프로젝트를 쓰지 않고 작은 웹앱을 직접 만든다. 다른 도구의 좋은 기능(Story Bible, 선택 수정, 후보 비교, 관계도)만 가져온다.

## 근거

- 소설 도구들은 모두 API 키 방식이라 추가 비용이 생긴다.
- 기능이 많고 무거워(Neo4j, 자동 연출 워크플로) 페르소나에게 어렵고, 대부분 중국어 UI다.
- CLI 웹 래퍼는 구독을 쓰지만 코딩용 화면이다.
