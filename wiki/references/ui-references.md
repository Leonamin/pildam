# UI 레퍼런스

2026-10-18 운영자가 공유한 이미지. 저작권 문제로 이미지 파일은 저장소에 넣지 않고 설명만 남긴다.

| # | 내용 | 가져올 점 |
|---|---|---|
| 1 | 어두운 테마 출판용 에디터. 왼쪽 목차, 가운데 종이 원고(장식 머리글, 드롭캡), 오른쪽 기기 미리보기·스타일 패널 | 종이 원고 중심 레이아웃, 세리프체 |
| 2 | 밝은 테마 원고 에디터. 왼쪽 원고 트리, 가운데 페이지 원고, 오른쪽 서식 패널 | 챕터 트리, 페이지형 원고, 넓은 여백 |
| 3 | AI 글쓰기 도우미. 왼쪽 아이디어 패널, 문장 선택 시 옆에 프롬프트 팝오버(Rephrase, Analyze grammar) | 선택 영역 AI 메뉴 팝오버 |
| 4 | Story Elements 보드. 인물 카드 노드와 관계 화살표, 오른쪽 요소 상세 카드 | 노드 클릭 → 상세 카드 |
| 5 | Story Architect 인물 관계 그래프. 관계선에 라벨(friendship, want to kill), 오른쪽 프로필·관계 탭 | 라벨이 붙은 관계선, 프로필 패널 |

추가로 운영자가 본 방식: 원문을 빨간 취소선, 새 버전을 초록 밑줄로 그 자리에 보여 주고 Yes/No 팝오버로 고르는 방식. [ADR 0008](../decisions/0008-inline-diff-for-selection-direct-insert-for-ghostwriting.md)에 반영.
